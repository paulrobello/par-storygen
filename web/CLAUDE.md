# par-storygen web frontend — Claude Code Guide

Agent-oriented guide for the Next.js frontend in `web/`. The full guide lives in `AGENTS.md` — it covers the App Router layout, the typed API client (`web/src/lib/api.ts`), the WebSocket + Zustand data flow, and the available scripts. The frontend is a thin client over the FastAPI server in `src/storygen_api/` and owns no game logic.
